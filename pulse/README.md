# Pulse archive

One file per edition of `pulse.md`, the living "what India is talking about" file in the Fave Claude Design system. The routine `fave-pulse` (Claude Code scheduled task, Mondays 08:30) researches the seven scenes, writes the new edition here as `YYYY-MM-DD.md`, copies it to `../pulse-publish/project/pulse.md` and publishes it to the system artifact (https://claude.ai/artifact/DN7a1y9Ec5XYJvNK8p9YyE). The README's *The moment* section tells Claude Design how to use it.

Scenes: UPI and fintech · Indian pop culture and cricket · Bollywood · Indian AI and tech Twitter · global AI design · global AI business · design Twitter, plus anything that makes a wedge for a UPI app in India right now.

The evergreen vocabulary, the playbook and the never list change rarely and by hand; the wedges and the calendar change every week.
